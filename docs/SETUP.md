# Checklist de ativação

1. Criar projeto no Supabase.
2. Executar `supabase/schema.sql`.
3. Ativar Email/Password em Authentication.
4. Criar plano de assinatura no Mercado Pago.
5. Configurar as variáveis de ambiente descritas em `.env.example`.
6. Registrar o webhook do Mercado Pago em `/api/webhooks/mercadopago`.
7. Fazer deploy.
8. Criar uma conta de teste.
9. Cadastrar negócio, serviço, profissional e horário.
10. Autorizar uma assinatura e testar um agendamento público.

Este arquivo também participa do PR usado para validar o build completo do MVP via GitHub Actions.
